# 聊天室工具弹窗

2026-11-07。

红包、弹幕、涂鸦由聊天区内联展开改为共用 `ChatToolDialog`，复用 `FpDialog` 的 Teleport、遮罩及过渡。经典/简约布局仅保留同一份弹窗，工具按钮使用 `aria-haspopup=dialog` 和展开状态；不重复挂载编辑器。

红包按类型、金额/份数、留言和操作区排布；弹幕显示真实价格、文字、颜色及纯文本预览；涂鸦画布位于上方，底部集中颜色、笔触、撤销、清空和插入操作。涂鸦仍只插入当前编辑器草稿，不自动发送。

弹窗打开时锁定页面滚动并聚焦可用控件，Tab 焦点保留在当前弹层，关闭后恢复滚动和原工具按钮焦点。费用确认使用已有顶层对话框；此时禁止关闭底下的工具弹窗，取消确认仅返回表单。关闭工具仍卸载其编辑器，沿用原有取消上传/本人确认、草稿和未确认命令生命周期，不增加持久化。

- `npm run build` 通过，原有 FeedbackView 导入提示仍在。
- 本机浏览器验证三种弹窗、经典/简约布局、弹幕预览、Esc 关闭与焦点恢复、Tab 约束、红包二次确认取消。未确认付款、发红包或发送付费弹幕，未写入线上数据。
- 390px 视口的涂鸦弹窗宽 350px、画布宽 308px，弹窗自身完整显示。底层经典编辑器既有最小宽度未在本次改动中处理。
