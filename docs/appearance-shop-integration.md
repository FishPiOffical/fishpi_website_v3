# 积分外观商城接入（2026-11-12）

## 用户入口与行为

外观模块新增「外观商城」入口，使用全局弹窗，不增加路由。商城有座驾、气泡、头像框三个分类和「我的外观」筛选。商品按后台配置支持 7 天或 7/30 天，点击价格后确认；不会自动装备或续费。

- 座驾：派派小电驴、摸鱼纸飞机、深海潜艇。
- 气泡：海盐汽水、落日邮笺、星夜航线。
- 头像框：潮汐、派派邮票、星环。
- 免费和纯 VIP 外观保留原入口。普通积分外观独立授权。
- 夜樱雨气泡 256 积分 / 7 天，夜樱雨头像框 128 积分 / 7 天。有效 VIP 可直接装备，非 VIP 可单独周租。商城可主动预览动效；经典、简约和悬浮聊天室只对实时新消息播放，历史使用静态快照。精简模式隐藏外观，减少动态偏好关闭动画。
- 续期从 `max(服务器当前时间, 原到期时间)` 累加。到期后新消息使用默认外观，历史消息仍使用发送时快照。
- 座驾一次装备一个，卸下不删除购买权益。到期装备不播报，续期后恢复原选择。
- 装备座驾后，服务端在公开在线状态允许时推送进场事件；批量读取权益，不逐人请求。座驾替换该次管理员进场文案，退场仍沿用原管理员配置。
- 前端从左侧播放 4.1 秒，不拦截页面点击；最多同时播放 3 条，新提示从底部加入，已有提示平滑上移，移除后平滑收拢；另保留 3 条等待队列，15 秒过期丢弃。遵循减少动态效果偏好。左侧设置的聊天输入栏目可关闭座驾动画，文字公告仍保留。
- 新后端 ready 帧声明 `presenceControl:true`，新版前端才发送 `chat.presence` 帧。首页仅接收聊天消息；聊天室页/悬浮聊天室参与进场。旧后端不识别此能力时不发送新帧；旧客户端保留原进场行为。多标签页继续按用户合并，短暂重连不重复入场（现有节点内注册表范围）。

## 数据与失败处理

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/v3/appearance-shop?includeVipWeekly=1` | 有界商品目录、服务器价格、报价版本、上下架状态及 VIP 周租商品 |
| GET | `/api/v3/me/appearance-items` | 本人权益、到期时间、座驾装备、余额、服务器时间 |
| POST | `/api/v3/me/appearance-purchases` | `productId/days/revision`，幂等购买或续期 |
| PUT | `/api/v3/me/appearance-mount` | `productId` 装备，空字符串卸下 |
| PUT | `/api/v3/me/chat-appearance` | 复用原气泡/头像框装备接口 |

购买/装备携带 `Idempotency-Key`。未知结果保留原内容和原键；令牌正常轮换不清命令，换号/退出清理。写成功后的库存读取失败只重读，不能重扣。商品修价必须同步递增 `revision`，旧报价拒绝后重新确认。内置外观继续使用本地白名单。后台发布的聊天气泡返回固定结构的配色与角标，角标图片只接受指定 RhyPic HTTPS 域名，配置不含可执行 CSS。

## 发布顺序

1. 备份数据库，在 Rhythm 数据库执行 `sql/20261112_appearance_shop.sql`，库前缀非 `symphony_` 时替换前缀。
2. IDEA 编译并手动重启 Rhythm，再确认四个新接口及原聊天外观接口。
3. 构建发布 website_v3 客户端与 SSR 产物；商城和进场效果从 RhyPic 加载透明座驾缩图。

内置商品仍由原商品表维护。新气泡由独立 backend 项目的「会员与资产 → 外观管理」维护。Rhythm 先执行 `sql/20261116_chat_bubble_style.sql`，四款宠物气泡以未发布草稿加入。免费和 VIP 气泡由外观设置读取，积分气泡使用现有商城；所有用户消息以发送时的快照渲染。回滚不要删除权益、购买流水或幂等回执。

## 已验证与边界

- 前端类型检查及客户端/SSR 构建。
- `node tools/appearance-shop-test.mjs`：响应丢失恢复、重复扣款防护、令牌轮换、换号拒迟到、写成功读失败、新样式白名单。
- 隔离 Chromium API/WS 夹具：1440、1024、768、390 宽度（浅色与暗色）的购买确认、装备、动画、自动清理、无横向溢出；未使用真实积分。
- Rhythm SQLite 专项：购买/续期、索引失败回滚、凭据撤销、旧报价、余额不足、未购买/到期装备拒绝、历史快照不变；现有外观及实时注册表回归通过。
- Java 专项使用隔离 SQL/传输夹具；积分适配器在同事务模拟余额/流水，不替代 MySQL 多进程并发及真实服务器联调。真实迁移、服务重启、真实双账号进场和管理员数据库改价仍需部署环境验收。本次未部署。

四款宠物气泡草稿在 Rhythm 执行 `sql/20261116_pet_bubble_shapes.sql` 后使用版本化的异形轮廓。前台和后台复用相同的轮廓渲染，矢量路径按气泡尺寸绘制，贴纸单独排版。消息没有 `shape` 字段时继续使用原样式。

夜樱雨在基础商城迁移后执行 Rhythm 的 `sql/20261116_night_sakura_appearance.sql`。发布前用有效 VIP 和普通账户分开测两件商品，包括零扣分装备、7 天扣费、租期结束后的新消息和旧历史，再于 PC、手机验证新消息入场与减少动态。
