## 制作与复现

- 十项均由内置 imagegen 生成，九项引用上述两张派小鱼身份图；外出第二版先从已认可原图生成站立参考，再仅引用站立参考画动作。每个动作单独生成一张 **RGBA、4 × 4、16 个连续绘制帧** 的源图，没有混合多种动作。九项源图为 1254 × 1254；外出第二版实际为 1261 × 1247，由同一导出工具按四行四列提取。
- [sources](sources/) 中每个 `{action}.md` 保留了完整实际提示词和原始输出 basename，`{action}.png` 是原始输出的直接副本。
- 每段仅有 **16 个绘制帧**；通过不同停留时长放入 24fps 视频时间轴。24fps 不表示每秒有 24 张独立新画帧。没有光流补帧、自动过渡帧或身体拆分后的骨骼变形。
- 导出沿用共享工具，只分离 4 × 4 网格、统一比例缩放和落脚基线对齐，再编码 VP9 与 WebP。同一动作内保持同一缩放比例，保留生成图透明通道。
- 吃的是小饼干，喝水使用小杯；没有捕食其他宠物，也没有增加服装或其他角色。

在仓库根目录运行，需安装含 `libvpx-vp9` / `libwebp` 的 FFmpeg 和 Chrome：

```sh
PET_FFMPEG=/absolute/path/to/ffmpeg node tools/pet-animation-export.mjs --species=paixiaoyu
node tools/pet-animation-preview.mjs --species=paixiaoyu
```

导出可在物种参数后追加 `idle eat` 等动作 ID，仅重新导出指定项。导出所用 Chrome 是独立的本地图片提取实例，不借用用户登录浏览器。

## 基本检查与未验收边界

[基本检查结果](basic-validation.json) 记录了十项文件的实际大小、帧数、时长与透明像素：

外出第二版另见 [专项素材检查](explore-v2-validation.json)：48 个输出帧均完整解码并检查实际透明与实体像素，尺寸 256 × 256、24fps、2 秒；源图保留 16 个绘制帧。其余九段视频及九张静态预览逐文件哈希与修正前一致。

- 十张源图均为 RGBA；源图目视检查为各自独立的 4 × 4 连续帧。角色保持重绘版圆胖造型，未发现明显额外手脚、帽子漂移或其他宠物。
- 十张 WebP 均为 256 × 256 RGBA，包含透明及实体像素。
- 十段 WebM 均用 FFmpeg 的 `libvpx-vp9` 解码器完整解码，帧数与清单一致；逐段提取首帧为 RGBA 并检查透明及实体像素，尺寸均为 256 × 256。时长与清单差小于 0.02 秒。
- 原始生成图在边缘留有极低 alpha 的色素，源图透明通道未做额外去背或阈值重绘。实际显示效果仍需在统一预览中检查。
- 连续重绘会有轻微轮廓差异，首尾姿势相近，不宣称逐像素无缝。原地小步等动作幅度较小，动作识别、流畅度及角色一致性的最终结论留待用户统一验收。
- 本批未执行应用构建、全量业务或浏览器交互验收；没有将编码和基础素材检查通过视为艺术验收。未修改 `src/`、Rhythm、账号数据，也没有改动现有开发服务或八小时持续检查。
