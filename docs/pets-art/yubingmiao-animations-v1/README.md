# 鱼饼喵动画首版候选

2026-11-13。为已确认的橘白鱼饼喵制作十个独立动作，保留蓝项圈、小金鱼吊牌与橘白条纹尾巴；外出 v2 去掉手持蓝鱼，让步态清楚可见，其余动作保留蓝鱼。本批仅交付候选美术素材，**尚未接入家园或桌宠，也未完成用户艺术验收**。

外出 v2 修正了用户指出的“坐着走”：先重画站立姿势参考，再生成全程站立的 16 帧步行循环。臀腹离地，两条短腿位于腹下并前后交替，脚尖朝右，两前爪反向轻摆；不再用坐姿抱鱼图锁定动作。只替换 `explore` 的源图、视频与静态预览，其余九个动作的 WebM/WebP 字节保持不变。完整新旧来源与提示词见 [外出制作记录](sources/explore.md)。

打开 [独立动作预览](preview.html) 查看透明 WebM，或查看 [整套动作对比视频](overview.mp4)。对比 MP4 只用于快速观看，游戏候选素材仍是十段独立透明 WebM；本轮没有执行预览页面、家园或桌宠的浏览器交互验收。

## 制作与复现

- 十项均使用内置 `image_gen`，以已查看的 `public/images/pets/yubingmiao.webp` 为角色身份参考，没有使用 CLI/API fallback。外出 v2 先从身份图重画 [站姿参考](sources/explore-v2-standing-reference.png)，再用该站姿生成连续帧，没有引用错误的旧外出源图。
- 每动作一张透明 4×4 连续帧图，实际输出为 1254×1254 RGBA PNG。完整实际提示词、工具模式及原始输出文件名保存在 [sources](sources/) 的十份 Markdown 中；选用的源图逐一保存为同名 PNG。
- 每段有 **16 张原绘帧**，以各帧停留时长形成节奏，再编码为 24fps 时间轴。24fps 不代表每秒 24 张独立新画帧；没有光流插帧、自动过渡补帧或骨骼变形。
- 外出 v2 的 16 张原绘帧各停留 3 个时间轴帧，共 48 帧 / 2 秒；其余九项保持原节奏。
- 导出只分离连续帧、使用同一动作统一缩放比例并对齐落脚位置，再输出 256×256 WebM 与 WebP。源图透明通道原样保留，没有重新去背或重绘角色。
- 使用杯子、书、球和布巾时，把原蓝鱼放在尾巴旁边；前爪转去操作当前道具，不在抱鱼手臂之外新增手爪。

在仓库根目录运行，需含 `libvpx-vp9`、`libwebp` 的 FFmpeg 与 Chrome：

```sh
PET_FFMPEG=/absolute/path/to/ffmpeg node tools/pet-animation-export.mjs --species=yubingmiao
node tools/pet-animation-preview.mjs --species=yubingmiao
```

可在导出命令后追加 `idle eat` 等动作 ID，仅重新编码指定动作。制作过程未修改应用源码、其他宠物素材或原 `website_v3` 工作区，也未重启开发服务或八小时持续检查。

## 基本检查与未验收边界

- 源图逐张查看：十张均为单动作 4×4，保留鱼饼喵身份特征；未发现额外前爪或后足。不同帧仍有轻微轮廓、道具和表情重绘差异。
- 十张源图均为 RGBA，各格包含透明像素；以 alpha≥128 读取的实体边界均未接触分格边缘，当前最小余量为 7 源图像素。
- 十张 WebP 均为 256×256 RGBA。
- 首版用 FFmpeg 的 `libvpx-vp9` 解码全部视频帧，确认每段实际 256×256、输出帧数符合清单，且每帧同时包含透明像素与实体像素。该历史记录保存在 [validation.json](validation.json)，其中旧 `explore` 已标明被替代。
- 当前外出 v2 另行逐帧解码：实际为 256×256、48 帧 / 2 秒，每帧透明与实体像素均通过检查；新视频 173,223 字节、WebP 22,200 字节，其他九项共 18 个文件的 SHA-256 与修正前一致，详见 [explore-v2-validation.json](explore-v2-validation.json)。
- 对待机源图额外合成深底检查：透明预览器显示的彩色低 alpha 像素在实际合成中不可见；没有据此修改原始透明通道。
- 首尾为相近姿势，未声明逐像素无缝。动作幅度、循环衔接、深浅底与实际 128px/256px 观看效果仍待用户最后统一验收。**编码与透明度检查通过不代表艺术验收通过。**
- 按本次范围未执行完整浏览器验收、业务测试、应用构建、真实设备或其他浏览器验证；没有把素材制作扩大为功能接入。
