# 鱼饼喵动画首版候选

2026-11-13。为已确认的橘白鱼饼喵制作十个独立动作，保留蓝项圈、小金鱼吊牌与橘白条纹尾巴；外出去掉手持蓝鱼，让步态清楚可见，其余动作保留蓝鱼。本批仅交付候选美术素材，**尚未接入家园或桌宠，也未完成用户艺术验收**。

当前外出 v3 修正了用户指出的近远腿交换：使用 4×2 八个 contact/down/pass/up 关键姿势，近侧奶白腿始终位于前层，远侧整条腿保留暖灰米色阴影和后层位置。支撑脚沿右→左，摆动脚离地左→右；臀腹始终离地。导出全程使用同一锚点，避免跟随各帧最低脚点移动整只宠物。只替换 `explore` 的源图、视频与静态预览，其余九个动作的 WebM/WebP 字节保持不变。完整来源与提示词见 [v3 制作记录](sources/explore-v3.md)，[旧版记录](sources/explore.md)保留为历史。

打开 [独立动作预览](preview.html) 查看透明 WebM，或查看 [整套动作对比视频](overview.mp4)。对比 MP4 只用于快速观看，游戏候选素材仍是十段独立透明 WebM；本轮没有执行预览页面、家园或桌宠的浏览器交互验收。

## 制作与复现

- 十项均使用内置 `image_gen`，以已查看的 `public/images/pets/yubingmiao.webp` 为角色身份参考，没有使用 CLI/API fallback。外出 v3 使用已重画的 [站姿参考](sources/explore-v2-standing-reference.png)与八姿势脚轨迹指南，没有引用错误的旧外出源图。
- 外出当前源图是 1774×887 RGBA、4×2 八关键帧；其余九项保留 1254×1254 RGBA、4×4 十六帧。完整实际提示词、工具模式及原始输出文件名保存在 [sources](sources/)；选用源图逐一保存为同名 PNG，不另存重复候选图。
- 外出有 **8 张原绘帧**，其余九项各有 **16 张原绘帧**；以停留时长形成节奏，再编码为 24fps 时间轴。24fps 不代表每秒 24 张独立新画帧；没有光流插帧、自动过渡补帧或骨骼变形。
- 外出 v3 的八张原绘帧各停留 3 个时间轴帧，共 24 帧 / 1 秒；其余九项保持原节奏。
- 导出只分离连续帧、使用同一动作统一缩放比例，再输出 256×256 WebM 与 WebP。外出 v3 共用锚点 [217.5, 410] 与缩放 0.58，不再按每帧最低脚点重新对齐；源图透明通道原样保留，没有重新去背或重绘角色。
- 使用杯子、书、球和布巾时，把原蓝鱼放在尾巴旁边；前爪转去操作当前道具，不在抱鱼手臂之外新增手爪。

在仓库根目录运行，需含 `libvpx-vp9`、`libwebp` 的 FFmpeg 与 Chrome：

```sh
PET_FFMPEG=/absolute/path/to/ffmpeg node tools/pet-animation-export.mjs --species=yubingmiao
node tools/pet-animation-preview.mjs --species=yubingmiao
```

可在导出命令后追加 `idle eat` 等动作 ID，仅重新编码指定动作。制作过程未修改应用源码、其他宠物素材或原 `website_v3` 工作区，也未重启开发服务或八小时持续检查。

## 基本检查与未验收边界

- 源图逐张查看：外出当前为单动作 4×2，其余九项为单动作 4×4，保留鱼饼喵身份特征；未发现额外前爪或后足。外出 v3 的完整图及腿部放大已经过交叉审查，确认近远腿颜色与层次可连续追踪。不同帧仍有轻微轮廓与表情重绘差异。
- 十张源图均为 RGBA，各格包含透明像素；以 alpha≥128 读取的实体边界均未接触分格边缘，当前全套最小余量为 8 源图像素，外出 v3 为 11 像素。
- 十张 WebP 均为 256×256 RGBA。
- 首版用 FFmpeg 的 `libvpx-vp9` 解码全部视频帧，确认每段实际 256×256、输出帧数符合清单，且每帧同时包含透明像素与实体像素。该历史记录保存在 [validation.json](validation.json)，其中旧 `explore` 已标明被替代。
- 当前外出 v3 另行逐帧解码 RGBA：实际为 256×256、24 帧 / 1 秒，每帧透明与实体像素均通过检查；新视频 56,547 字节、WebP 17,220 字节，其他九项共 18 个文件的 SHA-256 与修正前一致，详见 [explore-v3-validation.json](explore-v3-validation.json)。旧 [v2 检查记录](explore-v2-validation.json)已标明被替代。
- 对待机源图额外合成深底检查：透明预览器显示的彩色低 alpha 像素在实际合成中不可见；没有据此修改原始透明通道。
- 首尾为相近姿势，未声明逐像素无缝。动作幅度、循环衔接、深浅底与实际 128px/256px 观看效果仍待用户最后统一验收。**编码与透明度检查通过不代表艺术验收通过。**
- 按本次范围未执行完整浏览器验收、业务测试、应用构建、真实设备或其他浏览器验证；没有把素材制作扩大为功能接入。
