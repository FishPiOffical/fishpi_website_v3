## 制作与复现

- 全部十张源图均使用内置 imagegen，并指定透明背景；没有使用 CLI/API。原始输出复制到 [sources](sources/)，每项 Markdown 记录实际提示词、参考和原始输出文件名。
- 外出源图为 1774 × 887 RGBA，含 **8 个独立绘制关键帧**；其余九张为 1254 × 1254 RGBA，各含 **16 个独立绘制帧**。编码通过停留时长形成节奏，输出为 24fps 时间轴；**24fps 不代表每秒绘制了 24 张新帧**。
- 没有光流补帧、自动过渡帧、身体拆分或骨骼变形。导出只分离源帧、等比例缩放和编码；外出八帧共用固定锚点，不逐帧追着脚尖或尾巴移动整图。每个动作全程使用同一缩放比例，保留原始透明通道。
- 首尾是相近姿态，存在生成式逐帧绘制的轻微轮廓及道具位置差异，不承诺逐像素无缝循环。睡觉保留闭眼微笑；是否需要更明显的睡姿、吃鱼表现和动作幅度，由整套视觉验收确认。

在仓库根目录运行，需支持 `libvpx-vp9` / `libwebp` 的 FFmpeg 和 Chrome：

```sh
PET_FFMPEG=/absolute/path/to/ffmpeg node tools/pet-animation-export.mjs --species=momota
node tools/pet-animation-preview.mjs --species=momota
```

可在导出命令末尾添加 `idle eat` 等动作 ID，仅重导指定动作。临时分帧及解码结果位于 `.temp/momota-animations-v1/`。
