# 聊天室侧栏设计

## 本次落地

侧栏服务于聊天：优先显示话题、时间和个人活跃状态，把低频操作收起来。沿用站点主题变量，不另造一套配色。

- 卡片统一为 8px 圆角、细边框、14px 内边距，模块间距 10px。
- 标题 12px，辅助文字 11px，正文 12px；话题 14px，下班倒计时 26px。
- 标题配统一线性图标。点击标题折叠/展开，状态随现有侧栏配置保存在本浏览器；排序、开关继续在设置里管理。
- 当前话题保留绿色强调，编辑框按需展开，保留提交失败时的草稿。
- 在线成员默认显示 8 人，双列紧凑布局；展开后可按昵称/用户名搜索。显示数量来自已加载的在线成员列表。
- 活跃度保留原有签到与奖励操作，移除嵌套卡片，进度条与按钮使用站点主题色。
- 外观选择以小色块和名称显示，选中态使用细边框；保留 VIP 标记和原有权限判断。
- 弹幕花费突出数值；思过崖统一空状态与列表排版。
- 新增侧栏连接状态，复用共享聊天室状态，不发起额外连接。

## 建议新增的模块（设计方案，尚未实现）

默认关闭新增模块，由用户按需添加，避免右栏持续变长。新模块统一登记到 meta.ts / registry.ts，继续支持拖动排序与折叠。

| 优先级 | 模块 | 展示与交互 | 数据与边界 |
| --- | --- | --- | --- |
| P1 | 常用入口 | 2×2 小按钮：聊天、隐藏消息、屏蔽设置、社区公告；隐藏消息附数量 | 复用现有弹窗/设置状态与公告路由；无额外请求；未启用屏蔽时给出设置入口 |
| P1 | 稍后回复 | 从消息操作菜单加入，侧栏显示头像、两行摘要、时间；点击回到原消息，可移除 | 需要新增按账号隔离的本地收藏存储；原消息撤回/找不到时明确提示；不要默认为跨设备同步 |
| P2 | 近期热议 | 最多 3 条标题与回复数，底部「更多」；无大封面，降低对聊天的干扰 | 复用首页真实热议接口和缓存；失败显示空状态，不填充模拟文章；避免每条新消息都请求 |
| P2 | 休息提醒 | 展示下一次提醒时间，提供开始、暂停、结束；支持 25/50 分钟预设 | 本地时间戳计时，刷新可恢复；用户主动开启；仅站内提示，浏览器通知另行授权 |
| P3 | 房间公告 | 一条简短公告、发布日期及详情链接 | 先确认聊天室公告接口；没有接口时仅链接到现有社区公告列表，不把当前话题冒充公告 |

建议先做「常用入口」和「稍后回复」，分别减少寻找操作入口和错过消息的成本。近期热议适合偏社区浏览的用户；休息提醒作为自选工具。房间公告等待后端数据支持后再落地。

## 验收重点

浅色/暗色下标题和正文可读；经典/简约聊天布局均无横向溢出；长昵称省略、话题正常换行；收起后键盘不进入隐藏内容；刷新后排序、开关与折叠状态保留。验证时不发送消息、不更新现网话题、不领取奖励。
