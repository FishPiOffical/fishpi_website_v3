# 首页布局拖动调整

- 设置 → 首页模块 → 拖动调整布局进入编辑模式。
- 九点 SVG 手柄替换字符图标；整条 44px 高的模块标题栏可拖动，正文不启动拖动。
- 保留上下堆叠、左右新增列、行间新建行及现有布局自动保存。未编辑时不增加标题栏。
- 拖动预览使用整张卡片，原位置淡化；落点显示具体插入方向。行间落点固定高度，不再在经过时撑开页面。
- 手柄可聚焦，用上下方向键在相邻模块间调整顺序，左右键按相邻模块新建列。跨列后恢复焦点，退出编辑清理拖动状态。
- 原生浏览器拖放仍用于桌面；本次没有新增触屏拖放实现。

## 验证

- `node tools/home-drag-test.mjs`：编辑权限、预览节点、上下排序、左右分栏、新建行、键盘焦点、退出取消及迟到 drop。
- `node tools/v3-home-dom-test.mjs`：布局恢复、独立版本保存、SSR 水合和 DOM 恢复专项通过；既有夹具有 isChatroom 未定义警告。
- `npm run build`：类型检查及客户端、SSR 构建通过。
- 隔离浏览器样例复用实际拖动逻辑、模板及样式，1440/390px 排版检查，浏览器合成拖放事件验证跨列堆叠通过。样例不访问真实 API，不代表人工鼠标/触屏端到端验收。
