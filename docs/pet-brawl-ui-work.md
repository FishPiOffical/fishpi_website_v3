# 宠物乱斗页面与入口调整

2026-11-17。本次只调整 website_v3 的页面组织和交互，不修改 Rhythm、战斗数值、费用或奖励。

## 页面组织

- 家园入口抽为 `PetBrawlEntry`：显示当前宠物立绘、等级和 Lv.10 门槛；未解锁仍可进入查看说明。
- 乱斗页沿用站内颜色、字体、图标和页面宽度。顶部集中展示宠物、历练材料、闯关与当日奖励进度。
- 对战大厅：回放与出战操作分栏，玩家对战、闯关陪练独立切换，下方保留真实战报与游标分页。
- 配装工坊：武器与招式、强化进度、神器和镶嵌分区；积分与材料商店继续复用 `FpDialog`，突出余额、抵扣和实际扣款。
- 赛季榜单：赛季时间横排，榜单与本人战绩分栏，保留原有赛季切换、分页、上榜条件及奖励领取。
- 窄屏改为单列；宠物静态图使用现有 RhyPic 二倍缩图工具。回放沿用 WebM 与手机、省流、减少动态的静态回退。

## 状态与可用性

- 三个分区通过 `v-show` 保留组件与配装草稿，订单的读取、确认和恢复逻辑不变。
- 离开大厅暂停回放；隐藏分区收到迟到战报也不自动播放或滚动。
- 切换分区支持方向键、Home、End，内容区切换按钮把焦点移至目标页签。
- 身份边界清理当前分区和武器、招式、关卡选择；战报定位的异步间隔再次核验身份。
- 报名、匹配、强化、镶嵌、报价、扣款和领奖继续调用原处理函数。未保存的报名配置仍禁止匹配。
- 出战、强化、赛季与回放操作区接入现有 `data-floating-obstacle`，桌宠临时避让，不修改已保存的位置偏好。

## 本地验证

- `npx vue-tsc -b`、`npm run build` 和 `npm run test:pets` 通过。
- 本地测试账号：家园入口进入乱斗、武器跨分区保留、模式切换、真实赛季和订单读取、战报出招/受击播放、分区切换暂停、方向键及焦点返回通过。
- 1440、1024、768、390、320px 检查三分区，无页面横向溢出；390px 商店弹窗无内部横向溢出。
- 浅色与暗色主题在切换过渡完成后截图核对；立绘解码完成后复核布局。桌面三个分区和手机战报操作区均通过桌宠避让检查。
- 浏览器仅替换读取响应的 UI 夹具：Lv.9 锁定、已报名后修改配装禁止匹配、503 锁定与显式重读、手机减少动态静态回退通过。夹具不修改本地数据库。
- 本轮浏览器验收没有产生乱斗写请求，不重新验证已在前批完成的真实扣款/领奖事务，也不将读取检查当成消费验收。
- 本地截图与检查记录位于 `/tmp/fishpi-brawl-redesign/`；最终以本地运行页面供人工验收，不推送、不部署。

## 视觉门禁边界

设计技能门禁输出 `GATE: FAIL 12 (round 2 of 3)`。其每次使用新的浏览器资料，访问私有乱斗页后被正常重定向到登录页，因此没有检验到乱斗界面；本次用已登录浏览器补充实测与截图。

未修改的登录页及公共页脚发现项：登录/注册点击目标、客户端小图标及页脚支付链接点击目标（4项）；登录页纯文字判断（1项）；赞助区按钮样式及高度差异（4项）；客户端下载链接对比度（1项）；页脚外链图标未载入（1项）；登录表单边界判断（1项）。门禁的 1440px consistency 检查未完成。这些不作为本轮乱斗页面通过的证据，也不扩大修改范围。

现代布局参考 `responsive-design` 与 `css-layout`：媒体预留 `aspect-ratio`，网格列使用 `minmax(0, …)`，可变文本项允许收缩；移动端通过实际换列适配，不用隐藏页面溢出来掩盖布局问题。
