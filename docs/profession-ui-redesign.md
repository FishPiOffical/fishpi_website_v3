## 实现

参考 Rhythm 经典站的职业设置和职业排行模板，沿用本站的字体、浅色/暗色主题、绿色主操作与橙色名次强调。

- `/settings/profession`：主职业摘要、两列职业选择卡片、职业进度、等级路线、贡献及经验记录、展示范围。窄屏卡片和隐私字段单列。当前职业明确标记，经验增减区分颜色，已知经验来源显示中文。未知来源保留原值，避免错误解释。
- `/top/profession`：职业切换、简介、成长提示、排名/用户/等级/经验四列榜单；窄屏每条分两行，保留真实排名与经验未公开状态。
- 两处共用的成长提示改为来源与奖励两栏，失败重试采用带可访问名称的小图标；保留原有请求时机、认证边界、分页、设置及恢复行为。
- V3 目录和榜单没有提供经典站的图标展示字段，本次采用旧版缺图时的首字标识，不编造职业图标、不为每张卡片追加请求。
