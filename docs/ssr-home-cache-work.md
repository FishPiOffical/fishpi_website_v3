# 首页 SSR 与加载优化

2026-11-07。

## 原因与处理

原服务每次生成首页均重新读取十项公开资源，成功结果没有跨请求复用；个人卡片无条件挂载后重读并清空 SSR 资料，清风列表也无条件重读。首页文章、标签、专栏在 SPA 返回时没有短期复用。

现在首页匿名公开 DTO 按资源缓存 5 分钟，包含并发合并、容量上限和逐请求克隆。失败不缓存、空结果可缓存，缓存键包含上游地址。SSR 载荷仍由每个 app 注入，不共享 Pinia、身份、Cookie 或完整 HTML。首页预取失败日志仅记录资源名和 HTTP 状态。SSR JSON GET 最长 8 秒（包括正文读取），不会重试写入。

浏览器首页五资源缓存 5 分钟，只在内存存放；手动读取绕过缓存。缓存绑定稳定认证版本、登录状态和用户 ID，身份边界同步清除；同身份重验保留可见内容，错误仍清旧内容并显示重试。过期后进入首页重新读取。普通令牌轮换不视为换号，但会重新核验当前数据。其他页面、排行榜和实时聊天不使用这个浏览器缓存。

个人卡片及清风有有效游客 SSR 数据时直接复用，登录后仍读当前权限；个人卡片同身份重验不先隐藏资料。不能将此理解为全站无网络请求或登录私有数据已 SSR。

## 验证

- `npm run build` 通过（原有 FeedbackView 静态/动态导入提示仍在）。
- `npm run test:v3`：106 项通过，包含缓存 TTL、并发合并、克隆隔离、失败不缓存、容量限制、SPA 复用、手动刷新、认证隔离及原有 SSR/DOM 检查。
- 本机只读代理连接真实公开 v3 GET，拒绝所有写入和真实身份恢复；连续首页请求从约 2.12 秒降至 0.013 秒，第二次十项成功资源均未再次访问上游。这是本机样本，不代表线上响应时间保证。
- 浏览器验证首页水合、热门页导航及返回，首页九个模块在 DOM 中，未见水合警告。未测试真实账号登录或私有写入。
- 现网服务器直读公开文章/标签/专栏已可成功；另一组服务器实测的两个榜单返回 401，这类上游拒绝保留独立错误，不冒充成功或填零。本次不修改 Rhythm。

这些改动尚未部署到线上。

后续调整：首页服务端与浏览器缓存统一为 5 分钟，测试覆盖第 1 分钟仍命中、第 5 分钟过期。首页及通用内页侧栏的清风明月统一使用聊天室已有的头像加内容格式：20×20 头像，不显示用户名和时间；主列表及个人动态保持原格式。专项缓存/首页/清风测试及完整构建通过，浏览器确认首页八条、内页侧栏六条均使用同一紧凑格式，无水合警告。
