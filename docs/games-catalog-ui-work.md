# 鱼游页面布局优化

2026-11-07，范围为 `/games`。

参考总榜的渐变引导区、分组编号、线性图标与卡片边框，重排官方游戏、活动小游戏和社区鱼游。增加分区锚点及总榜入口，官方入口直接导航经典站点，不带本站凭据。社区卡片使用接口实际图标、简介、作者及赞踩数；图标失败使用通用游戏图形，不假造品牌图标或评分。

社区列表桌面三列，较窄屏幕两列，手机单列。选中卡片展开当前详情并定位，翻页后回到社区列表顶部。排序、真实分页、详情读取、三态投票、评论、编辑和未知命令恢复继续使用现有 v3 实现，未修改 API 或投票语义。

详情重排图标、作者、打开游戏入口及表态，评论与主体分隔。合法空评论不再显示“1 / 0”分页。投稿表单默认折叠，“分享游戏”入口同时展开并定位；收起不会卸载表单或清草稿。五个必填字段、OAuth 说明、提交审核及原键恢复保留，表单提示改成面向用户的简短说明。

验证：

- `npx vue-tsc -b` 与 `npm run build` 通过；原有 FeedbackView 导入提示仍在。
- `tools/v3-fish-games-test.mjs` 的 18 组测试通过，包含分页排序、详情、投票/评论/投稿/编辑、认证切换、迟到请求、幂等恢复与 SSR 外壳。
- 本机浏览器以只读代理访问真实公开鱼游 GET，拒绝所有写操作，核对 20 条首屏卡片、第二页、排序控件、详情及五字段投稿展开。未向真实站点投稿或投票。
- 390px 窄屏页面宽 390px，无横向溢出，社区列表为单列；浏览器未见运行警告或错误。
- 尚未部署线上。
