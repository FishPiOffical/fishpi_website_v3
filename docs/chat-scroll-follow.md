# 聊天室底部跟随修复

简约模式原来在所有 scroll 事件中重新判断跟随状态，动画或浏览器布局调整也可能使其退出跟随；消息容器作为 flex 子项可收缩，不能保证 ResizeObserver 观察到内容真实增高。悬浮聊天室只在消息更新后 nextTick 滚动一次，未覆盖延迟图片和后续布局变化。

两处共用 useChatScrollFollow / createChatScrollFollow：
- 用户滚轮、触屏、键盘和滚动条操作决定暂停／恢复；布局导致的滚动不取消跟随。
- 观察滚动容器与消息内容尺寸；列表稍后挂载时重新绑定，动画、图片与叠卡增高持续贴底。
- 翻阅历史暂停跟随，保留原有历史锚点恢复；显式返回最新或向下滚到底部恢复。
- 简约消息内容不参与 flex 收缩；两处关闭原生滚动锚定，避免与主动定位竞争。
- 不增加任何接口、轮询或发消息行为，经典模式方向不变。

验证：类型检查与完整构建通过。tools/chat-scroll-follow-browser-test.mjs 使用本地浏览器夹具验证两种容器的延迟挂载、260ms 动画、晚到图片、上翻不抢位置、回底恢复、历史加载和清理。运行时通过 PLAYWRIGHT_MODULE 指向本地 Playwright，或使用已安装的 playwright 包。测试不登录、不发送真实消息；真实长时间收信仍待人工体验。
