# 《Q宠大乐斗》规则调研

调研日期为 2026-11-16。用户提到的「Q宠物大乱斗」，本文按腾讯 QQ 空间页游《Q宠大乐斗》理解。《Q宠大乐斗Ⅱ》的技能栏和手动回合另有规则。原官网本次查阅时超时，以下依据历史报道、厂商稿和开发者采访，适用范围为各来源所述版本。摸鱼派的方案见[宠物乱斗开发设计](pet-brawl-design.md)。

| 原作机制 | 查到的规则 | 摸鱼派怎么用 |
| --- | --- | --- |
| 好友挑战 | 历史手机版可以主动挑战好友、即时结算、获得经验和道具，并保留乐斗记录，与网页端同步。 [2010 年手机版发布报道](https://games.sina.com.cn/o/n/2010-11-03/1501449079.shtml) | 采用异步挑战和战报。先做相近等级的实装匹配，点名约战放后续。 |
| 战斗过程 | 早期资料描述战斗由实力与运气共同决定，武器、技能和趣味解说增加观赏性。厂商的 iPhone 版发布稿还介绍了跳过演出直接看结果。回顾文章明确把早期玩法概括为点击后自动战斗。 [2010 年早期体验](https://games.sina.com.cn/o/n/2010-06-13/1425408604.shtml) · [2012 年 iPhone 版发布](https://news.17173.com/content/09132012/164748539.shtml) · [2024 年玩法回顾](https://finance.sina.cn/tech/2024-06-05/detail-inaxqxat3097941.d.html) | 后端一次结算，桌面和手机复用战报回放，可以直接跳到结果。 |
| 成长与装备 | 早期升级有机会取得技能或武器，也可能进入「潜心修炼」。制作组采访确认了武器升级系统和概率平衡问题。 [2010 年早期体验](https://games.sina.com.cn/o/n/2010-06-13/1425408604.shtml) · [开发组采访](https://games.sina.com.cn/o/n/2010-05-19/1413400799.shtml) | 保留招式差异和回合随机性。基础招式与武器免费选择，强化和装备成长进入实装对战。 |

| 付费商品 | 2014 年活动出现 Q 币限定礼包，也有药水等实用道具的 Q 币促销。 [新年礼包预订公告](https://m.juxia.com/news/2014-12-19/132242.html) · [3 月更新公告](https://m.juxia.com/news/2014-3-27/115147.html) | 保留单独的消费入口，装备养成、额外挑战、消耗品和外观统一使用站点积分。详见[积分消费方案](pet-brawl-points.md)。 |

早期体验的核心是点一下就开打、招式有辨识度、打完能回看。精确技能概率、武器数量、体力恢复时间和每日收益上限缺少统一的跨版本依据。开发方案里的数值均为摸鱼派首测提案，角色、道具名和素材使用本社区设定。
