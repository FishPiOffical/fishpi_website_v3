# 聊天室小尾巴

入口位于左侧设置的「聊天室输入 → 小尾巴设置」。账号设置通过独立的 `/api/v3/me/settings/chat-tail` GET/PUT 保存，不存入浏览器 localStorage；默认关闭，关闭保留文字。弹窗关闭设置抽屉后打开，避免叠加遮罩。

## 协议与边界

- 设置为 `{ enabled, text }`，仅单行纯文字和 Emoji。上限 24 个扩展字素、512 个 UTF-16 单元；前端 `Intl.Segmenter` 的计数用于提示，后端 Java 25 `\X` 为最终校验。旧浏览器缺少分段器时由服务端校验，不用字符串长度假称可见字数。
- PUT 使用原幂等键恢复未知结果，成功后仅重新 GET。普通令牌轮换保留草稿，退出、换号清理本人状态并拒绝迟到结果。
- 配置由后端在 V3 普通消息首次成功提交时读取，消息保存独立 `tail: { text }` 快照；正文 `content/contentHtml` 不拼接尾巴。设置后改文字，不影响历史。
- 普通文字、Unicode Emoji、图文及带自己文字的引用可附加；纯图片（含多图、图片表情、涂鸦）、纯引用、红包、音乐、天气、弹幕、系统通知和旧版发送不附加。
- 小尾巴与正文一样接受后端内容校验。无权限或撤回的消息不返回尾巴，坏尾巴字段不使有效正文丢失。

## 展示

聊天室经典/简约、悬浮聊天室、隐藏会话与上下文共用 `ChatBubble` 的纯文本 `.fp-chat-tail[data-chat-tail]`。精简模式即时隐藏所有人的尾巴，不改变本人发送设置。首页简易聊天室只展示正文，私信不展示。

引用和复读仍只处理原正文；复读后由服务器附加当前发送人的尾巴，不复制对方尾巴。列表、详情与实时推送携带快照，无逐条用户配置查询。

## 本地验收

1. 后端先执行小尾巴 SQL 迁移并重启；前后端必须配套更新。
2. 登录测试账号，打开弹窗，开启并保存文字；发送普通消息，确认气泡底部显示尾巴。
3. 修改尾巴后再发一条：新旧两条分别保留各自的尾巴。关闭设置后发送不再附加。
4. 测试 24/25 字、家庭 Emoji、国旗、肤色、组合音标及换行；超限拒绝，不截断草稿。
5. 检查纯图、多图、纯引用和特殊卡片不附加；图文和引用加文字正常附加。
6. 开关精简模式检查即时隐藏/恢复，切换经典/简约及悬浮窗口检查一致；首页预览不带尾巴。
7. 换号不显示前一个账号的配置；保存失败保留草稿，未知结果沿用原键恢复。桌面及移动端分别检查弹窗关闭、焦点和输入。

本地自动化结果不代替实际人工验收；本轮不自动部署。
