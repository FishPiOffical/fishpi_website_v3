# 红包详情与聊天室操作提示

红包详情统一为红金色头部、领取进度、初始奖池、税额和领取记录。普通、拼手气、专属、心跳及猜拳沿用同一详情组件。猜拳使用三个独立手势按钮；选择手势不领取，提交前仍显式确认风险。双方出拳、胜负、负积分和发送者退款仅展示当前详情接口实际返回的数据。

聊天室顶部不再常驻显示发送、红包、撤回、话题等操作的成功回执。失败、结果未确认及提交后读取失败仍提供原请求键恢复或仅重读入口；不删除 store 中的回执，不改变消费与消息协议。

## 验证

- 红包专项覆盖选择手势不提交、风险确认、原键恢复、负积分和领取后当前详情刷新；撤回专项仍核验实际费用回执，仅取消成功文案展示。
- 浏览器通过本机身份与接口夹具检查普通红包、猜拳待出拳/胜负、心跳扣款、已领完、详情失败及重试；390px 宽度详情保持在视口内。
- 本机夹具预置成功回执，确认顶部无成功提示。未向真实站点发送消息或执行红包消费。
