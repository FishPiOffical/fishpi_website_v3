# 内页侧栏标签布局

2026-11-14：内页和聊天室共用 `SidebarLayout`。“我的资料”保留独立置顶，其余模块可在左侧设置中选择“独立卡片”或“标签页”，支持两种形式混排。

## 范围与操作

- `SideBar` 覆盖文章列表（最新、热门、问答、优选等）、清风明月、关注、同城、标签和领域页。
- `ChatSidebar` 同时覆盖经典与简约聊天室。
- “我的资料”启用时固定在侧栏顶部，保留原内容、卡片样式及 `SidebarModuleHeader` 折叠交互，沿用原侧栏 store 的 `collapsed` 偏好，不进入标签列表。
- 设置中的启用、禁用、拖动及箭头排序继续生效，每个模块另有展示位置选择。独立卡片按原排序排列；所有标签集中到一组，放在排序中第一个标签模块的位置，标签内部也沿用原顺序。资料卡固定置顶。配置齿轮放在第一个独立卡片或标签组右上角，收起后也能点击；全部关闭时仍保留配置入口。
- 只启用独立卡片时不显示空标签框；全部模块关闭时保留标签空态和齿轮。独立卡片恢复原折叠摘要，签到和清风明月摘要由模块读取结果提供。
- 标签保持单行横向滚动，溢出时可用两侧箭头浏览，当前标签用底部短线标记；不再重复显示标题行。长内容在当前面板内滚动。
- 首页的模块布局、拖动、折叠，以及页面专属的榜单分类、文章目录、个人资料卡均保持原状。
- 左侧设置分为页面布局、聊天体验、个性化与反馈，保留所有原设置入口；外观商城复用已有商城弹窗，关闭设置后打开，不新建购买流程。

## 加载与状态

- 标签模块首次选中才挂载；已经访问的模块隐藏后保留实例、输入和分页，切换标签不重复触发挂载读取。独立卡片挂载后折叠不卸载。改变展示位置会重新挂载该模块；清风未发送草稿及原提交关联通过当前侧栏内存上下文保留，不写入本机存储。关闭模块、退出或换号、离页销毁侧栏时清空；普通令牌轮换保留。
- 关闭模块时卸载；当前模块被关闭后，选择设置排序中的第一个启用模块。
- 普通访问令牌轮换保留当前实例；身份边界或账号变化重建资料卡及旧面板，避免旧身份内容或草稿跨账号保留。
- 游客也显示已启用的签到标签，内容提示登录；不会在认证恢复前把记住的签到标签覆盖成其他模块。
- `fp.sidebarTab.pageSidebar.v1`、`fp.sidebarTab.chatSidebar.v1` 只保存最后选中的标签模块 ID，不保存面板数据或草稿；旧值为 `profile` 时回到第一个已启用标签。
- `fp.pageSidebar.v1` 与 `fp.chatSidebar` 原键中增加 `presentation`，旧偏好默认资料独立、其他标签，不丢弃原排序、关闭与折叠记录。模块暂时关闭仍保留展示位置，恢复默认会重置位置。存储拒绝时本次调整仍可用。
- SSR 与客户端挂载前均显示统一准备态；本机偏好只在挂载后参与布局。换号时清除独立卡片摘要和面板内状态。
- 左右方向键、Home、End 移动标签焦点，回车或空格打开模块。仅移动焦点不触发模块读取。

- `node tools/sidebar-presentation-test.mjs`：15 组展示偏好、旧配置迁移、排序/显隐/折叠独立、分组和存储失败测试。
- `node tools/sidebar-layout-ssr-test.mjs`：48 种侧栏配置仅输出准备态，不挂私人模块、不读取本机存储。
- `node tools/sidebar-drafts-test.mjs`：真实清风输入组件在两种位置间移动保留草稿，未知命令关联、卸载期间完成及身份边界清理；`node tools/v3-breezemoons-test.mjs` 验证原有发布、修改、删除和恢复行为。
- `PLAYWRIGHT_MODULE=<playwright 模块路径> node tools/settings-drawer-browser-test.mjs`：9 组设置面板检查，覆盖分组导航、展示位置、旧配置箭头排序、拖动、持久恢复、商城联动、聊天输入开关及窄屏明暗主题。
- `PLAYWRIGHT_MODULE=<playwright 模块路径> node tools/sidebar-layout-browser-test.mjs`：10 组混合布局、折叠、草稿迁移、惰性加载、身份隔离、空状态和响应式检查；资料与上下班模块使用真实组件及隔离数据。
- `node tools/sidebar-tabs-ssr-test.mjs`：服务端不读取本地存储，不挂载私人模块，空配置和不同模块配置均输出准备态。
- `PLAYWRIGHT_MODULE=<playwright 模块路径> node tools/sidebar-tabs-browser-test.mjs`：真实共享组件在 Chrome 中验证惰性挂载、草稿保留、排序与禁用、空状态、存储恢复与失败、账号隔离、键盘操作、桌面与窄屏滚动、浅色和暗色。
- `npx vue-tsc -b` 与 `npm run build`：类型检查和客户端、SSR 构建。
- 隔离页面接入真实内页与聊天室模块，验证资料、上下班时间、签到、清风明月和外观；390px 窄屏无横向溢出，600×500 矮屏内容内部滚动，清风草稿切换后保留，游客签到提示正常。

浏览器验证使用隔离夹具，不向真实账号提交内容，也不改动正在运行的本地服务。
