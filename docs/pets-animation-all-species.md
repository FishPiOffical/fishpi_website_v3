# 四种宠物动画接入

本轮把已确认的摸摸獭、鱼饼喵、派小鱼动画接入宠物家园和桌宠，与荷小豚共用播放器及状态切换。未修改 Rhythm、养成规则、数据库或视频源文件，也未重新编码素材。

## 展示与触发

- 四种宠物各有十个 256 × 256 透明 WebM 动作：待机、喂食、饮水、抚摸、玩耍、睡觉、外出、上课、工作和庆祝。
- 日常互动仍由现有业务操作更新状态；只有当前宠物的成功确认才触发短动作。动画不能代替状态更新，未知结果不提前播放成功动作。
- 长期动作跟随当前活动快照；活动到期待领取时恢复待机。领取补给成功后播放庆祝。
- 物种和动作使用本地白名单，不读取额外目录接口，不逐宠物请求动画配置。换宠、物种变化或身份清理会清除旧短动作，未知物种保留静态图。
- 家园和桌宠复用同一状态来源，视频只加载当前可见动作。桌宠收起、离开视口和页面隐藏时停播；省流、减少动态效果或视频失败时回退静态图。
- 三只新接入宠物沿用上一轮确认的节奏：外出放慢，喂食、饮水、抚摸、玩耍加快，待机与睡觉保持不变。播放速率仍为 1，不再次叠加调速。
- 领养选择列表仍使用静态图。导出工具保留素材目录的接入标记，后续调整节奏不会把已接入素材重新标为仅预览。
