# 聊天室复读与弹幕运动

2026-11-07。

- 经典和简约聊天室移除音乐、天气发送按钮及编辑面板。已有卡片继续展示，原发送恢复入口保留，避免在 SPA 中留下无法确认的旧命令。
- 新增共享 `ChatRepeatAction`，接入两种聊天室布局和悬浮聊天内的聊天室。只传消息 ID，显式点击后读取当前 v3 详情，普通文字及图片 Markdown 使用现有发布流程发送；不从消息列表 HTML 拼正文。红包、音乐、天气及不可用消息不复读。
- 复读读取期间阻止重复点击；离页、身份或目标变化取消读取并拒绝迟到发信。已发送但结果未知时由既有 publication store 保留原键、正文并恢复；仅本地命令增加 `origin: repeat`，HTTP body 不加字段。恢复复读不向编辑器发清草稿事件。
- 弹幕原来只有 0.4 秒右上角入场动画，之后静止。现在从 `translateX(100vw)` 到 `translateX(-100%)` 匀速运动 8 秒，完整跨越视口；使用五条固定轨道，旧弹幕离开不挤动其他轨道。动画结束清理，8.5 秒备用定时器兜底；保留事件去重、五条上限、断连/退出清理及纯文本渲染，不遮挡页面点击。

验证：

- 全量 `npm run test:v3` 106 项通过；发布专项补测原文/图片换行、原键恢复、草稿隔离、双击和离页取消、不可用源与游客限制。弹幕专项额外验证稳定轨道、复用空轨道及动画结束清理。
- `npm run build` 通过，保留既有 FeedbackView 导入提示。
- 浏览器使用仅本机消息接口验证：复读生成新的本人消息，原文与原消息一致；经典/简约模式均有入口且无音乐、天气发送按钮。没有向线上发送消息或付费弹幕。
- 本机弹幕实测横坐标由约 1223px 移到 -39px，并在结束后从 DOM 清除；内容按文本呈现。夹具未提供目标用户路由的提示不代表正式路由缺失。
