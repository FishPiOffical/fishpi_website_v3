# 2026-11-07 测试报告：前端优化

## 范围

仅修改 website_v3，不修改后端协议、签到方式、热门算法、优选门槛或登录方式。报告中的数据与产品设想不直接当成站点规则。

- 首页默认经典版，SSR/客户端首帧一致；已保存的经典/紧凑选择及位置显隐继续保留，预览浏览器已通过设置切到经典。
- 首页、公共列表、专栏以及无Bearer的公开文章在已成功显示内容时设置公开标记。网络故障保留已有内容，顶部提示并可重试；无内容的首次失败保留offline逻辑。身份边界、当前401/403/404仍清理，登录文章不借公开快照保留付费或受限正文。
- 列表相同页网络错误保留数据；翻到未成功的新页不沿用旧页冒充新页。公开重试事件只调用当前挂载的读取，不重发写命令。
- http仅对无signal、无显式headers/body且选项受限的公开列表GET合并在途请求；按完整路径、令牌、稳定身份及缓存/凭据参数隔离，每消费者独立克隆。完成后不缓存；SSR、私有读取、收费操作、上传、带取消信号的请求均不合并。现有首页五分钟缓存保留。
- 聊天室无草稿时可收起编辑器，输入区48px，聚焦/展开后100px；不销毁Vditor、不替换Markdown草稿，不减少原工具功能。有草稿时保持展开。
- 在线侧栏默认预览8位，共用原在线store/total，重复连接复用近期或在途读取；用户主动刷新仍读取，未改变采样口径或默认模块位置。
- 热门与优选解释既有真实排序/用途，不添加不受支持的筛选、入选门槛或理由。
- 专栏卡片缩小封面、压缩文字、显示真实更新时间，取消与排序重复的角标；缺封面使用ID颜色和书名首字，不覆盖用户已有封面。试读使用接口实际提供的章节，不假称第一章。大屏三列，窄屏单列。
- 阅读进度仅在本浏览器保存最多100个专栏的最后章节ID，不保存正文、标题、凭据，不同步账号。目录提供继续阅读和上次读到；目标当前访问权限仍由阅读路由GET验证，旧目标失效不恢复历史正文。
- 首页提供可访问主标题，签到状态明确status，装饰图片保留空alt；时间准备态与专栏加载预留空间。搜索空态提供缩词提示、最新与标签入口；支持卡降饱和并标注站点支持。
