# 宠物乱斗积分与成长方案

2026-11-16 复核版，配套[开发计划](pet-brawl-design.md)。已确认乱斗付费用站点积分、战斗养成带来实战提升、人均消费目标 10,000–30,000 积分。下列价格、幅度和产速为待验证提案。

## 消费如何进入战斗

武器强化、神器、魂珠、符石与助战作用于当前出战装备，进入 NPC 和主要实装 PvP 的服务端快照。购买确认显示升级前后的实际效果，固定 NPC 可用于比较成长前后的表现。

强化属性逐级提高，所有效果进入同一成长预算。出战仅带一件武器、一招、一颗魂珠、一枚符石和一位助战，多个物品用于切换打法。免费材料与积分获得相同等级物品时效果相同。外观明确展示视觉效果，消耗品单列本局作用。

永久成长跨观察周期与赛季保留。重新领养保留账号资产、材料、首通和日额度，解除旧宠装备，新宠到 Lv.10 后可重新装备。积分与现有宠物币分别记账。

## 首套成型的价格原型

旧稿武器全强化仅 224 积分、神器 256 积分，缺少能支撑 10,000–30,000 积分预算的完整目录。用下表做成长账本，阶段 3 先开放武器五档，其余部分随效果验证逐项开放。累计金额包含该项目从初始到目标状态的全部阶段。

| 成长项目 | 分档积分费用 | 累计 | 材料抵扣 |
| --- | --- | --- | --- |
| 武器 +1 至 +5 | 200 / 400 / 800 / 1,400 / 2,200 | 5,000 | 支持 |
| 神器进阶 | +5 武器保留强化，仅收进阶费用 | 2,000 | 支持 |
| 第二槽 | 首槽随基础装备开放，第二槽一次解锁 | 1,000 | 支持 |
| 一颗魂珠至三级 | 500 / 1,000 / 1,500 | 3,000 | 支持 |
| 一枚符石至三级 | 500 / 1,000 / 1,500 | 3,000 | 支持 |
| 一位助战至三级 | 500 / 1,000 / 2,500 | 4,000 | 支持 |
| 一套完整成长 | 上述六项合计 | **18,000** | 按已有材料降低实扣 |

基础武器和招式免费取得，逐档收取成长费用。每项成长只处理当前物品一次，满级时显示已完成。魂珠、符石可免费拆卸转移，同一物品同一时刻只占一个槽位，助战成长归账号。

第二套武器的强化、神器及第二槽合计 8,000 积分，可共用已有镶嵌物与助战。首套加一套替换武器的全额积分预算为 **26,000**。材料、打造、合成与融合都服务于表中的成长节点，每个配方列明完整成本和产物。增加配方时核对直接升级的等价费用，避免为同一等级重复计算打造和合成成本。

## 免费进度与部分支付

首发统一一种不可交易的「历练材料」，用于战斗成长，每单位可抵扣配方中的 10 积分，材料只有消耗用途。每日前三场完成的 NPC 对局给 5、5、10 单位，共 20，等价配方预算 200 积分。胜败奖励相同，首通先给成就与关卡解锁。已有食品、宠物币与工作产物各按原有用途使用。

| 全勤免费路线 | 计算 | 活跃日 |
| --- | --- | --- |
| 首次武器 +1 | 200 / 200 | 1 |
| 武器 +3 | (200 + 400 + 800) / 200 | 7 |
| 武器 +5 | 5,000 / 200 | 25 |
| 首套完整成长 | 18,000 / 200 | 90 |

表中假设目录全开放、每日三场完成并集中使用材料，描述材料供给进度。真实通关速度还须验证 NPC 数值。

报价默认展示材料抵扣与积分差额，由用户确认分配。800 积分的一档，用 30 材料抵扣 300 后扣 500 积分。确认时重验材料版本、余额与报价，材料被其他标签页使用后重新报价。以后售材料包时核对单位价格与直接升级的等价成本，折扣计入经济模型。

付费节点确认后立即获得其成长效果。高级节点依赖前置成长和 Lv.10 门槛，已买节点无需额外等待天数。首轮免费、部分积分和全额积分路线都能达到同一装备等级上限。

## 人均目标如何验证

完整目录开放后，以账号首次参战作为其 90 天观察起点，每账号只进入一个批次，零消费参战者计入分母。记录窗口开始前的已有资产与消费，新参与者和早期参与者分别展示并汇总全部账号，避免把尚无商城的早期时段混入完整玩法测量。净消费为窗口内实际乱斗扣款减对应退款/冲正，同时看付费率、付费人均、中位数、P90、项目占比和余额区间。窗口结束后发生的关联退款也修正原批次指标。

**全体参战者人均 = 付费比例 × 付费者平均净消费。** 18,000 和 26,000 是完全用积分获取配装的预算，使用免费材料会降低实扣。人均 10,000–30,000 是真实行为目标，须经灰度数据验证。

| 假设付费比例 | 付费者人均 18,000 时 | 付费者人均 30,000 时 |
| --- | --- | --- |
| 30% | 5,400 | 9,000 |
| 50% | 9,000 | 15,000 |
| 70% | 12,600 | 21,000 |

这些比例尚无实测支持。旧稿假设 35% 免费且单账号最高消费 30,000，则全体人均理论上限只有 19,500。该硬上限撤下，通过有限出战槽位与最高成长等级控制战力。到达消费目标区间下沿后继续观察留存与对战质量，极端消费单独查看。

按已开放目录验收阶段目标。阶段 3 只有武器成长，其全额价格 5,000 积分，完整玩法的人均目标在后续阶段评估。消费低于目标时先分析参与率、免费材料抵扣、商品价值和余额分布，再调整后续商品与供给。永久成长完成后还需看复玩率，先通过可替换打法和挑战内容提供长期目标。

## 消费事务与订单恢复

报价订单免费创建，保存本人、操作、目标物品、期望资产版本、材料分配、积分金额、目录版本和有效期。状态为待确认、已完成、已取消、已过期。成功终态关联实际流水与结果，数据清理必须保留消费去重依据。

鉴权后先读订单终态，已完成返回原结果，首次确认才验当前价格、材料、余额和风险。价格或资产版本变化时重新报价，旧成功订单仍可查询。确认、取消与过期清理使用相同锁单或条件更新约束，待确认只允许进入一次终态。积分转账锁在根事务前取得，购买或成长将扣积分、双边流水索引、材料净变化、资产与订单终态一起提交，付费开战额外同事务提交本局战报。

SPA 保留订单 ID 和原幂等键，普通令牌轮换保留，换号清私有状态。整页刷新后从本人订单列表核对。订单 ID 的唯一结算约束跨幂等缓存清理有效，成功后读余额失败只重读。确认请求失败或正文断流先查询原单。

新旧版积分记录显示具体项目与订单号，分别沿用当前授权及显示清洗。测试价格变化、余额不足、材料并发使用、双标签确认、确认与取消及过期清理竞争、提交后断流、跨日奖励、风控重试、换宠与旧订单重放，每批核对实扣、材料和成长效果。
