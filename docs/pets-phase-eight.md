# 宠物家园第八批：荷小豚动作接入

本批将已有十个 256 × 256 透明 WebM 动作接到家园和桌宠。没有新增动画素材，没有修改 Rhythm、业务规则、费用或数据库。其余三种宠物、领养选择列表仍使用原静态图。

## 动作与实际操作

- 喂食、饮水、抚摸、玩耍：写回执及随后的当前聚合状态都成功后，播放对应动作一次，再回到当前活动或待机。
- 领养、重新领养、领取活动成果、旅程奖励及每日补给：确认后播放一次开心动作。
- 手作成功：播放一次通用工作动作；改名和购买不播放庆祝。
- 休息、外出、课程和兼职：读取当前活动，分别播放睡觉、外出、上课和工作循环。到期或待领取时回到待机，不自动领奖，也不为了动画新增请求。

写入仍使用原幂等命令，成功后只读取原有聚合接口。API 适配器仅额外向调用方返回经过校验的 `petId`，核对回执目标是否还是当前宠物；不把回执当作养成状态。

未知结果、明确失败、写入成功但后置读取失败、迟到旧身份回执，以及回执与当前宠物不一致时，都不发成功动画信号。恢复原命令并核对成功后可以播放一次，单纯重新读取不会补播。

## 播放和资源控制

- `PetAnimation.vue` 共用媒体播放；`animations.ts` 为本地素材白名单；`usePetAnimationState.ts` 将当前活动与确认信号投影为动作。
- 不预加载整套资源，只加载当前可见动作。不查询素材目录，不增加业务 GET 或轮询。
- SSR 和客户端首帧均为静态图。视频实际解码后确认含透明及主体像素，才覆盖静态图，避免支持 VP9 但丢失透明通道时出现黑底。
- 离屏、切到其他浏览器标签、离开照顾分区、拖动或收起桌宠时停播。48px 收纳桌宠保持静态，展开时恢复当前活动。
- 支持系统减少动态效果、浏览器省流偏好；不支持视频、播放被拒或解码失败时保留原静态图。视频卸载时释放源与播放资源。
- 短动作的结束事件携带播放版本，不能清除后来开始的动作；另有 12 秒兜底，避免媒体失败后永久停留在短动作。切区、隐藏、换号、换宠及新操作都会结束旧短动作，重新显示不补播。
- 短动作信号仅内存保存，普通访问令牌轮换不清除。不会保存到本地存储、服务端或跨标签广播。

## 验证与当前运行环境

本轮验证使用本工作树的本地夹具和独立浏览器，不向真实站点写入测试数据。可复现命令：

```sh
npm run test:pets
node tools/pet-animation-browser-test.mjs
npm run build
```

验证结果：

- `npm run test:pets` 通过：API/状态 48 组、家园交互 39 组、桌宠摆放 11 组、动画状态 7 组、播放器 11 组，共 116 组。
- 类型检查及客户端、SSR 完整构建通过；保留原有 FeedbackView 静态/动态导入警告。
- Chrome 157 隔离浏览器 12 组通过：首屏只取待机、四照顾动作及回待机、未知恢复、四种活动与到期、庆祝、减少动态、离屏暂停、桌宠收起与隐藏、其他物种静态、省流以及媒体故障回退。390px / 320px 无横向溢出。
- 浏览器解码得到 256 × 256 帧，包含 32,033 个透明像素和 30,242 个主体像素，透明 WebM 实际生效。喂食、饮水、抚摸和玩耍均维持一次 POST 加一次聚合 GET，没有动画附加 API 请求。
- 报告与截图位于 `.temp/pet-animation-browser/`，没有意外资源失败或浏览器运行异常；`work.webm` 的一次主动故障用于验证静态回退。

以上为真实组件与本地模拟传输验证，不等同于真实账号业务人工验收，也不属于仍在运行的八小时长测。真实设备上的 Safari 透明 WebM 支持与省流策略仍需人工验证；播放器已经提供静态回退。

原 `website_v3` / `pet` 的八小时测试继续使用其固定源码与本地服务。本批保留在 `website_v3-pet-next` 的 `codex/pet-home-guidance` 工作树，不重启 5173、Rhythm 或改动测试数据库。用户已暂停 Sites 发布；本批只本地提交，不推送或部署。
