2026-11-07。

- 个人中心以左侧资料卡及上方 Tab 为身份与栏目入口。帖子、长文章、清风、回帖、职业、勋章、关系、收藏、匿名内容及积分子页去掉重复栏目标题；独立 `/stars`、`/points` 保留自己的标题，浏览器 SEO 标题不受影响。

- 统一内容留白、统计与刷新工具栏、分页分隔；关系及标签使用响应式网格，勋章使用紧凑卡片。

## 勋章读取原因

只读实测 `GET /api/v3/users/Yui/medals?p=1&size=20` 返回一条有效公开勋章；未登录的对应 `/medals/image?medalId=71&size=full` 返回 401（登录凭据无效）。Rhythm 当前图片路由使用 `profileRead`，前端原先在游客状态静默跳过图片读取。

保留既有认证边界，公开卡片展示真实名称、类型、说明、有效期，并在图案位置提供登录回跳入口。登录后继续用既有 Bearer SVG 接口和可撤销 Blob URL；失败保留错误及图片重试，不改用旧生成图片接口、不伪造勋章图案。提示仅用于公开勋章页，不向其他缩略勋章入口添加登录文案。
