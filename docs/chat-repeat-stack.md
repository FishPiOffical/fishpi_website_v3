# 聊天室复读叠卡

连续的普通文字／Unicode Emoji 消息按原始正文精确分组，不追加读取请求；通知、特殊卡片、引用、图片及富文本会断开分组。正文由现有 V3 消息快照透传到 ChatLine，不修改后端或历史消息。

经典、简约和悬浮聊天室共用 ChatRepeatList。首条消息决定对齐方向，最多三张后层加一张完整前层；更多消息展示总数。展开保留原消息的身份、外观、小尾巴和独立操作，+1 复用原有复读流程。精简模式不显示后层外观包。首页预览和隐藏会话暂不分组。

本地验证：
- `node tools/chat-repeat-test.mjs`：连续分组、通知边界、正文差异、特殊内容排除及原消息保留。
- `npm run build`：类型检查、客户端与服务端构建通过。
- Chrome 组件夹具：1000／560／390px 无横向溢出；展开、收起、计数更新、经典反序与清屏通过。夹具用模拟正文及操作按钮，不发真实消息；尚未用真实账号验证复读发送、撤回后的分组和长历史滚动。

本次只提供本地预览，不部署。
