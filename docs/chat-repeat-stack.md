# 聊天室复读叠卡

连续的普通文字／Unicode Emoji 消息按原始正文精确分组，不追加读取请求；通知、特殊卡片、引用、图片及富文本会断开分组。正文由现有 V3 消息快照透传到 ChatLine，不修改后端或历史消息。

经典、简约和悬浮聊天室共用 ChatRepeatList。首条消息决定对齐方向，最多六张后层加一张完整前层，每层外侧显示 20×20 头像，层间距 28px；更多消息展示总数。展开保留原消息的身份、外观、小尾巴和独立操作，+1 复用原有复读流程。精简模式不显示后层外观包。首页预览和隐藏会话暂不分组。

本地验证：
- `node tools/chat-repeat-test.mjs`：连续分组、通知边界、正文差异、特殊内容排除及原消息保留。
- `npm run build`：类型检查、客户端与服务端构建通过。
- Chrome 组件夹具：1000／560／390px 无横向溢出；展开、收起、计数更新、经典反序与清屏通过。夹具用模拟正文及操作按钮，不发真实消息；尚未用真实账号验证复读发送、撤回后的分组和长历史滚动。

本次只提供本地预览，不部署。

## 图片复读分组

连续图片按原图地址匹配，RhyPic 已知 `/w/尺寸` 路径和 `imageView2` 缩放参数归一到原图；其他参数、签名以及第三方地址保持区别。图文混排按清洗后的正文结构比较文字、空白、文字格式和图片顺序，图片 alt/显示尺寸不作为内容差异。链接、引用及特殊卡片不参与此次扩展；原消息不变，展开后仍使用各自原消息操作。

经典、简约和悬浮聊天室共用分组组件，不新增网络读取。`node tools/chat-repeat-test.mjs` 覆盖同图不同缩放、多图顺序、不同文字、签名和第三方参数、非法图片地址及通知边界；类型检查及完整构建通过。Chrome 本地夹具使用真实 ChatRepeatList 和实际外观 CSS，验证桌面/390px/560px、图片叠层头像可见、展开、实时计数及倒序；未在生产发送测试消息。
