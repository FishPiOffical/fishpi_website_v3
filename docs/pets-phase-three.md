# 宠物家园第三批：兼职与活动记录

本批在两仓 `pet` 分支接入六类见习工作、职业熟练度、工作履历和外出/课程/工作记录。仍用现有静态宠物，只消费独立宠物币，不消费站点积分，不新增动画、重新领养或生产部署。

## 玩法与服务端结算

| 工作 | 对应技能 |
| --- | --- |
| 配送见习 | 体能 |
| 巡游向导 | 探索 |
| 图书助理 | 知识 |
| 播报学徒 | 表达 |
| 手作学徒 | 手作 |
| 照护见习 | 亲和 |

- 六份工作都需要对应技能经验达到 10，即完成对应入门课程；不能拿其他技能或职业熟练度代替。
- 试运行每次工作 20 分钟，消耗精力 12、饱食 4、水分 6，无宠物币报名费；计划成果为 12 宠物币、15 宠物经验、3 心情、10 对应职业熟练度。
- 职业熟练度与课程技能独立，记录等级、累计经验和完成次数。工作不额外增加课程技能。
- 外出、课程、工作与休息继续共用单活动位置。到期仅显示待领取，不自动发奖，不轮询到期状态。
- 所有工作共用账号级每日 60 宠物币收入额度，按服务器上海时区的领取日结算；首次领养与每日补给不占额度。
- 剩余额度不足时只发剩余额度。额度已满不能开始新工作，但已完成工作仍可领取 0 币和其他成果，释放活动位置。未来重新领养不能重置账号额度。
- 原键重放不重复发工资、经验或熟练度；状态、钱包、收入额度、履历实际成果和回执由服务端同事务提交。

## 页面与数据

`/pets` 的活动区增加“兼职”，展示门槛、费用、预计收获、共享收入额度和六项职业熟练度。桌宠显示工作状态和领取入口。

活动区下方新增默认折叠的“活动记录”，提供全部、外出、学校、工作履历筛选和服务端分页。记录包括开始/结束或领取时间、已投入、预计成果与实际成果。第二批旧已领取活动缺失实际成果时明确显示“早期记录未保存成果明细”，不把计划奖励当成实发奖励。本批日志范围是计时活动，喂食/饮水等照顾动作仍不在此日志中。

| 资源 | 新增内容 |
| --- | --- |
| `GET /api/v3/pets/catalog` | `activityVersion: 2`、六项 `jobs` 和 `incomeRules` |
| `GET /api/v3/me/pet` | `income` 与 `pet.jobs` |
| `POST /api/v3/me/pet/activities` | 接受 `kind: work`，仍冻结宠物、工作和目录版本 |
| `POST /api/v3/me/pet/activities/claim` | 原接口领取、服务端结算实际成果 |
| `GET /api/v3/me/pet/activities?kind=all&p=1&size=10` | 本人活动记录，分类支持 `all / outing / course / work` |

履历使用独立 `petActivityHistory` store，展开才读，关闭/离页取消读取；主状态成功重读后仅已打开的履历重读一次。翻页、切分类和换号废弃迟到响应，普通令牌轮换保留同账号状态。跨日仅重新核对一次服务器状态，不在本地清空收入额度。私有宠物与履历不进入 SSR 或本地持久缓存。

## 人工验收步骤

1. 本地登录后进入 `/pets`，在兼职区核对六项工作门槛；未上课工作禁用，完成对应入门课并领取后可开始。
2. 开工后查看家园和桌宠倒计时；活动未结束不能再出发、上课或休息，结束后手动领取，核对钱包和对应职业熟练度。
3. 展开活动记录，按分类和页码检查外出、课程、工作；旧记录实际成果未知，新的记录显示服务端实发值。
4. 在另一标签页领取同一个活动，确认只有一次成果，原页重新同步；弱网恢复使用同一操作键。
5. 在桌面和 390/320px 窄屏检查三类活动切换、长名称、领取按钮、分页和桌宠。离开家园保留桌宠时不额外请求履历。
