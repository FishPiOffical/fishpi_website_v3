# 宠物静态素材（第一批）

四张图片均为 256 × 256 的透明 WebP，只用于基础养成的静态展示，没有新增动画或重新设计角色。

| 文件 | 角色 | 来源 | 处理 |
| --- | --- | --- | --- |
| `momota.webp` | 摸摸獭 | 本次会话已确认的宠物初设图 `exec-dceae52a-35d5-4bf0-89ab-7bdba64f47bd.png` | 提取上排左侧角色，去除边界连通的浅色背景、原图标题和标号 |
| `hexiaotun.webp` | 荷小豚 | 已修正多余小爪子的原动作图 `exec-122073be-324e-455f-af3e-7fc11c142b2d.png` | 提取第一帧，去除边界连通的浅色背景 |
| `yubingmiao.webp` | 鱼饼喵 | 同一宠物初设图 | 提取上排右侧角色；内部白色身体保留为不透明 |
| `paixiaoyu.webp` | 派小鱼 | 用户提供的「派小鱼」素材包 `14_周五啦.png` | 提取文字上方的完整角色与原有装饰，保留原透明通道 |

统一保留角色宽高比，缩放后居中放入画布，落脚位置靠近同一基线。原始素材未改动，运行时只读取本目录的本地文件，不依赖生成工具的输出目录或下载文件夹。

当前总大小约 65 KiB。UI 使用 `object-fit: contain`，不要把角色拉伸填满容器。派小鱼来自用户提供的贴纸，画风与另外三只不同是保留品牌形象的结果。

原始设计与素材的使用范围沿本项目用户授权，不代表提供第三方再分发许可。
